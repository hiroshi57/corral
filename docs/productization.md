# Corral 外販化（SaaS化）プラン

> Corral を「個人/社内ツール」から「売れるプロダクト」へ引き上げるための機能・戦略。
> 位置づけ: AIエージェント showcase の **追加案件 A1 / B=外販プロダクト候補**（原案1-8方式で MVP 稼働済）。
> 作成: 2026-07-24。

## ターゲットと差別化（確定）

- **ターゲット顧客**: Claude Code / Codex を業務導入し始めた開発チーム・受託/SIer。複数エージェントを並行運用したいが、タブ管理・レビュー・セキュリティに不安がある層。
- **課題**: ①並行運用の煩雑さ(タブ往復) ②レビュー/承認の属人化 ③ローカル実行のセキュリティ不安 ④海外ツールは英語UI。
- **差別化の核**: ①日本語ファースト＆国内コンプラ＆Chatwork連携 ②セキュリティ標準装備 ③エージェントFinOps ④全エージェント中立ハブ。
- **収益仮説**: 個人=OSS無償 → チーム/企業向け有償（SSO・監査ログ・リモート・共有ワークスペース）。

凡例: 層 = **F**ree / **T**eam / **E**nterprise、★ = 差別化 or 外販必須。

- 11/12 は課金を始めるための器

## リスクと防衛

- **リスク**: Orca/herdr 等の高速進化、Anthropic/OpenAI 公式が同種機能を内包、CLI仕様変更への追随コスト、ローカル→クラウド実行の技術難度。
- **防衛**: 差別化を「国内コンプラ・セキュリティ・FinOps・中立ハブ」に寄せる。汎用オーケストレーション競争には正面から挑まない。
